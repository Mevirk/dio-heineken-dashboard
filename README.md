# dio-heineken-dashboard

Projeto de conclusão de módulo referente ao conjunto de cursos voltados para a formação "Inteligência Artificial Aplicada a Dados com Copilot" ministrado entre parceria entre a DIO e a Heineken.

O arquivo de planilha anexado contém o dashboard desenvolvido conforme instruções apresentadas durante o curso e visa ser uma demonstração de uso do Microsoft Excel e de seus recursos de visualização de dados.

O uso do dashboard é simples e visa ser auto-explicativo sendo possível ao usuário modificar a apresentação das informações apresentadas através de mudança dos filtros disponibilizados.
